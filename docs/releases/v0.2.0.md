# AI Agent Monitor 0.2.0

## Highlights

- **Telegram integration with your own bot.** Browse live sessions, read history, review commands, answer approvals and questions, and send messages to supported Codex sessions. Guided setup stores the token in the operating system credential store. Bot replacement keeps the current connection until the new bot is activated.
- **Experimental Ubuntu GNOME frontend.** Native GTK interface with a GNOME Shell companion extension for the top-panel indicator, global shortcut, Wayland popup placement, and editor-window activation. Ubuntu is available from source; no prebuilt Linux package is included.
- **Direct Codex connection.** Codex approvals and questions use the local client connection instead of the previous Codex approval hook. Claude Code and Cline support remains experimental; Cline requests must be answered in Cline.
- **Clearer session activity.** Working, waiting, and unseen-completion indicators, per-application visibility, sticky application icons, and navigation to the corresponding editor or supported terminal tab.
- **Richer requests and messages.** Native Markdown messages, independently loaded history, command details, actual approval alternatives, multi-question forms, custom answers, and keyboard navigation.
- **Consistent interaction state.** Monitor-owned state with Tokio actors and channel subscriptions coordinates the window, notifications, and Telegram. Resolved requests retire across channels; stale and duplicate responses are rejected.

## macOS installation

Apple Silicon, macOS 13 or later. Intel Macs can build from source.

1. Download `AI-Agent-Monitor-apple-silicon.dmg` from this release once the assets are attached.
2. Open the DMG and drag **AI Agent Monitor** to **Applications**.
3. Launch the app from Applications and allow notifications when prompted.
4. Open **Settings → Integrations** to review detected agents. Codex requires no hook setup. Restart Claude Code after installing its hooks; enable hooks in Cline when using that experimental integration.

## Upgrading from 0.1.0

Review any legacy Codex approval hook previously installed for AI Agent Monitor and remove that obsolete entry while preserving unrelated hooks. The new Codex integration uses the local client connection and does not install or modify Codex hooks. Review **Settings → Integrations** after upgrading.

## Ubuntu installation

Follow the [Ubuntu installation guide](https://github.com/melsomino/ai-agent-monitor/blob/main/docs/ubuntu.md). The installer sets up the executable, desktop launcher, and companion GNOME Shell extension. GNOME may require a logout/login to load the extension. Ubuntu support is experimental.

## Compatibility and limits

- Agents are installed separately and must run on the same machine as the monitor.
- Telegram requires the computer to be awake and the monitor to be running. Messages pass through Telegram; no monitor-hosted relay is used.
- Notification presentation and available actions depend on operating system policy and permissions.
- Matching terminal-tab navigation is supported on macOS for Terminal and iTerm; it is not implemented on Ubuntu.
- Claude Code and Cline integrations are experimental and do not offer every Codex capability.
