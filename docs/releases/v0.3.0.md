# AI Agent Monitor 0.3.0

## Highlights

- **Browser access from your phone.** Enable Web access in the macOS popup settings, choose an address and scan the short-lived, single-use pairing QR. The switch enables LAN access and attempts a Cloudflare Quick Tunnel when `cloudflared` is installed. Account-backed ngrok (embedded SDK) and Tuna (installed official CLI) can connect at the same time, with independent setup and credential storage. A failed tunnel leaves LAN access available. Quick Tunnels are experimental and have no uptime guarantee.
- **Efficient live updates.** Authenticated WebSocket connections send incremental state changes, skip unchanged snapshots and negotiate compression. Previous-message requests use the same WebSocket connection. Clients resynchronize after gaps or reconnects.
- **Settings inside the monitor popup.** General, Applications, Agents, Telegram and Web share the existing window. Web settings show all available addresses without an inner scroller and adapt the window height to the content. Connection controls disappear while access is off.
- **Clearer interactions.** Approval scope details expand beside their action, message drafts grow as text wraps, and menu-bar counters put pending requests before unseen completions and working sessions. Native rendering and the interactive HTML prototype share these conventions.
- **Updated session monitoring.** Bounded chronological activities, current-action captions, restored live connections and support for Codex stream versions 11 and 13 improve session state and request handling.
- **Separate Telegram request messages.** Questions and approvals are delivered independently from browsed session cards, so a new request can produce a Telegram notification without changing the selected session.

- **Monitor-owned update checks.** Current and available versions are shared state, cached between launches and checked hourly. Interfaces show the installed version with a checkmark or an accented release link with a flame; they never perform their own update checks.
- **Refined desktop and browser controls.** Horizontal resizing, resize cursors, scrollable Markdown tables, light-theme contrast, composer delivery and disclosure behavior have been improved. The header includes a GitHub link. Telegram's `/web_access` command provides expiring connection links without a new keyboard button.
- **More resilient VS Code discovery.** A session remains discoverable when log rotation removes its membership event if its writer belongs to the verified live extension host. Explicit closed roles still take precedence.

## Installation and compatibility

The macOS binary targets Apple Silicon and requires macOS 13 or later. Open `AI-Agent-Monitor-apple-silicon.dmg` and drag the app to Applications. Intel users can build from source. Ubuntu GNOME remains experimental and is available from source; see [Ubuntu setup](../ubuntu.md).

Agents must run on the same computer as the monitor. The optional Cloudflare connector is installed separately (`brew install cloudflared` on macOS). The computer must remain awake and the monitor must be running for browser or Telegram access. A phone does not need a Cloudflare account or app. Cloudflare and Telegram can process traffic sent through their services; these integrations do not provide application-level end-to-end encryption.

See [Web access](../web-access.md) for pairing, network exposure, tunnel limitations and revocation behavior. Web access is off on application startup. Stopping it revokes browser sessions and stops the tunnel.
