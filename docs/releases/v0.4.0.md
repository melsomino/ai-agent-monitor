# AI Agent Monitor 0.4.0

## Highlights

- **Detach the monitor on macOS.** Use the pin in the popup's upper-left corner to move the monitor into a regular, movable window with native macOS controls and a Dock/Cmd+Tab entry. Pin it back from its title bar. Popup width and detached window position and size are remembered separately. Session expansion, drafts and scroll position survive the transition.
- **Compact approval details.** On macOS and in browser access, **Allow once** and **Allow similar** have integrated disclosure arrows with an internal divider. The main command and scoped prefix start hidden and expand independently below the action row. Clicking an arrow never sends a decision; clicking the action text does. Full command text remains selectable, and disclosure controls stay outside keyboard traversal.
- **Usage limit reset details.** Open the menu beside the Codex usage reset date to request available reset credits and expiration dates. A loading indicator appears while Codex responds. This is a read-only view: the monitor does not redeem a reset or start an agent turn.
- **Quieter, more responsive native updates.** The transient popup releases its UI when closed. Incremental Codex log reading avoids rereading the complete journal, and unchanged session rows and quota views retain their native controls. Updates are deferred during a held click so they cannot replace the pressed button. Action cursors use native pointing-hand regions.
- **Browser pairing survives monitor restarts.** Previously paired browsers retain their authorization for up to 30 days. Stopping Web access disconnects browsers and tunnels without deleting saved pairings. Explicit device revocation, logout and expiration still invalidate authorization. A changed public hostname can require pairing again.
- **Refined session presentation.** Sessions use a flat, application-aware natural order, app icons beside titles, compact metadata and an inset message-send control. The prototype and design specification document the updated controls and their platform differences.
- **Codex reliability improvements.** Terminal and VS Code session discovery, asynchronous question reconciliation and model-catalog handling have been refined. Log rotation and truncation are handled by the incremental reader rather than retaining an unbounded raw transcript.

## Installation and compatibility

The prebuilt macOS application targets Apple Silicon and requires macOS 13 or later. Open `AI-Agent-Monitor-apple-silicon.dmg` and drag AI Agent Monitor to Applications. Intel macOS builds and experimental Ubuntu GNOME support remain available from source; there is no prebuilt Ubuntu package in this release.

Agents must run on the same computer as the monitor. Browser and Telegram access require the monitor to be running and the computer to remain awake. Web access is off after application startup; enable it in Settings when needed.

Cloudflare Quick Tunnels are experimental and depend on the separately installed `cloudflared` connector. ngrok uses the embedded SDK and an account token; Tuna uses its official CLI and API key. Tunnel providers can fail independently while local-network access remains available. See [Web access](../web-access.md) for pairing, revocation and network limitations.
